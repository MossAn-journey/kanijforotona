# 漢読 — 大人のための漢字四択ドリル

漢字の読み方を四択問題だけで鍛える、シンプルな学習アプリです。
子ども向けの教育漢字ではなく、**社会人が仕事や新聞で出会う語**を中心に 127 語を収録しています。

## 使い方

`index.html` をブラウザで開くだけです。ビルドもインストールも不要で、オフラインでも動きます。

```
git clone <このリポジトリ>
cd kanijforotona
open index.html      # Windows なら start index.html / Linux なら xdg-open index.html
```

## できること

- **四択のみ** — 語を見て、正しい読みを 4 つから選びます
- **3 つの難易度** — 初級 / 中級 / 上級、または全部を混ぜて出題
- **魚偏モード** — 鮪・鮭・鯖など、身近な魚偏の漢字を 10 問出題
- **問題数を選べる** — 5 問 / 10 問 / 20 問
- **解答後に意味を表示** — 読めただけで終わらせず、意味と用例まで確認できます
- **苦手優先出題** — 間違えた語ほど先に、何度も正解した語は後ろに回します（オフにも切り替え可）
- **結果画面** — 正答率、取りこぼした語の一覧、間違えた語だけの復習
- **累計成績** — 解答数・正答率・習得した語・苦手な語ランキング（ブラウザ内に保存）
- **キーボード操作** — <kbd>1</kbd>〜<kbd>4</kbd> で解答、<kbd>Enter</kbd> で次へ
- ダークモード対応、スマートフォンの画面幅にも対応

## 難易度のめやす

| 難易度 | 内容 | 例 |
| --- | --- | --- |
| 初級 | 仕事や新聞で日常的に出会う語 | 相殺・出納・忖度・進捗 |
| 中級 | 社説や小説で見かける語 | 齟齬・邂逅・十八番・呉越同舟 |
| 上級 | 読めたら一目置かれる語 | 慫慂・膾炙・畢竟・光風霽月 |

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | 見た目（明朝体の見出し、ライト／ダーク両対応） |
| `data.js` | 出題データ（語・正しい読み・誤答 3 つ・意味・難易度） |
| `app.js` | 出題ロジック、採点、成績の保存 |

## 問題を追加する

`data.js` の配列に 1 行足すだけです。誤答は「ありそうな読み間違い」を選ぶほど良い問題になります。

```js
{ w: '出納', r: 'すいとう', d: ['しゅつのう', 'でのう', 'すいのう'], m: '金銭や物品の出し入れ。「出納帳をつける」', lv: 1 },
```

| キー | 内容 |
| --- | --- |
| `w` | 出題する語 |
| `r` | 正しい読み（ひらがな） |
| `d` | 誤答の選択肢 3 つ。**その語の読みとして正しくないもの**を入れてください |
| `m` | 解答後に表示する意味・用例 |
| `lv` | `1` 初級 / `2` 中級 / `3` 上級 |
| `cat` | テーマ別モードのカテゴリ。魚偏は `fish`（省略可） |

読みが複数認められている語（「施行（しこう・せこう）」など）は、正誤がつけにくいため収録していません。

## 成績の保存について

成績はブラウザの localStorage に保存されます。サーバーには何も送信されません。
消したいときは「成績」画面の「記録を消去」を押してください。
